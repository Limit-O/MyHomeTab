# The-Tab

Take control of your browser's new tab page.

The-Tab is a lightweight Chrome extension that no longer comes with a fixed bookmarks page. Instead, it's an "HTML container" — whatever HTML you paste becomes your new tab page.

## Features

- **Out-of-the-box default interface** — Large clock, date, search box, and common links. Ready to use right after installation
- **Switchable search engines** — Bing (default) / Baidu / Google
- **Fully customizable** — Paste or upload any HTML file, and it becomes your new tab page
- **Sandbox rendering** — Custom HTML runs in a separate iframe, free from extension CSP restrictions. Supports inline scripts, CDNs, and images
- **Non-intrusive UI** — No buttons, icons, or floating elements in your new tab page
- **Dedicated settings page** — Click the The-Tab icon in your toolbar to open the settings
- **Local storage** — Content is saved in `chrome.storage.local` (8MB limit), offline and private

---

### Replace with Your Own Interface

1. Click the The-Tab icon in your browser toolbar (if it's not showing, pin it from the puzzle menu)
2. Paste or upload a complete HTML file in the settings page
3. Click "Save"
4. Your new tab page instantly switches to your interface

To return to the default interface, click "Restore Default Interface" in the settings.

---

## Limitations of Custom HTML

Custom HTML runs in a sandbox iframe, which is Chrome's recommended way to render external content in extensions. Therefore:

- ✅ Inline `<script>` and `<style>`
- ✅ External CDNs (JS / CSS / fonts / images)
- ✅ `fetch` / `XMLHttpRequest`
- ❌ Cannot use `localStorage` / `sessionStorage` (sandbox is a separate origin)
- ❌ Cannot call `chrome.*` APIs (hard limit by Chrome)
- ❌ Cannot navigate the entire tab to an external URL (top-level navigation is disabled)

If you need to save data in custom HTML, use `indexedDB` or keep it as a pure display interface.

## Origin

This extension was originally a built-in bookmarks page, generated by DeepSeek with an initial version, then polished and released. Later, we realized: since AI can now generate beautiful HTML on the fly, why limit users to a single interface?

This led to the v2 redesign: the extension now handles "storage + rendering," while the interface is left to the user.

---

## Language Support

The-Tab supports both Chinese and English:

- **简体中文**: Select "简体中文" from the "Language" dropdown in the settings page
- **English**: Select "English" from the "Language" dropdown in the settings page

Language preference is saved locally and applied automatically on next open.
