## v2 更新说明

从 2.0 起，扩展不再内置书签界面，而是作为一个「自定义 HTML 容器」：

- 在设置页粘贴或上传任意完整的 HTML 文件；
- 该 HTML 会在沙盒 iframe 中渲染，成为你的新标签页；
- 支持内联脚本、CDN 资源、图片、字体；
- 设置页提供「上传 / 导出 / 清空 / 保存」；
- 内容保存在 `chrome.storage.local`，上限 8MB。

> 沙盒页面是独立源，`localStorage` 不可用，且不能调用 `chrome.*` API。
