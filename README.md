# MyHomeTab

把浏览器新标签页交给你自己。

MyHomeTab 是一个轻量的 Chrome 扩展，它不再内置固定的书签界面，而是一个「HTML 容器」：你想让新标签页长什么样，就粘什么 HTML 进去。

---

## 特性

- **默认界面开箱可用** —— 大时钟、日期、搜索框、常用链接，装完即用
- **搜索引擎可切换** —— Bing（默认）/ 百度 / Google
- **完全自定义** —— 粘贴或上传任意 HTML，它就成为你的新标签页
- **沙盒渲染** —— 自定义 HTML 在独立 iframe 中运行，不受扩展 CSP 限制，可内联脚本、可引 CDN、可贴图
- **无侵入 UI** —— 新标签页里没有本扩展的任何按钮、图标、悬浮元素
- **设置独立入口** —— 点扩展工具栏图标即可进入设置页
- **本地存储** —— 内容保存在 `chrome.storage.local`，上限 8MB，不联网、不上传

---

### 换成你自己的界面

1. 点击浏览器工具栏上的 MyHomeTab 图标（若没有显示，在拼图菜单里固定它）
2. 在设置页粘贴或上传一个完整的 HTML 文件
3. 点「保存」
4. 新标签页即刻切换为你的界面

想回到默认界面，在设置页点「恢复默认界面」即可。

---

## 自定义 HTML 的限制

自定义 HTML 运行在沙盒 iframe 中，这是 Chrome 官方推荐的扩展渲染外部内容的方式。因此：

- ✅ 内联 `<script>`、`<style>`
- ✅ 外部 CDN（JS / CSS / 字体 / 图片）
- ✅ `fetch` / `XMLHttpRequest`
- ❌ 无法使用 `localStorage` / `sessionStorage`（沙盒是独立源）
- ❌ 无法调用 `chrome.*` API（这是官方硬性限制）
- ❌ 无法把整个标签页跳转到外部地址（顶层导航被禁）

如果需要在自定义 HTML 中保存数据，可以使用 `indexedDB`，或者干脆做成纯展示界面。

## 目录结构  

MyHomeTab/  
├── manifest.json # 扩展配置  
├── index.html # 新标签页：默认界面 + 沙盒容器  
├── index.js # 时钟 / 搜索 / 界面切换逻辑  
├── background.js # 点击工具栏图标 → 打开设置  
├── sandbox.html # 沙盒渲染器  
├── settings.html # 设置页  
└── settings.js  

---

## 由来

最初这个扩展是一个内置书签页，用 DeepSeek 生成了初版代码，作者打磨后发布。后来意识到：既然 AI 已经能随手生成漂亮的 HTML，何必限定用户只能用某一种界面？

于是有了 v2 的改造：扩展只负责「存储 + 渲染」，界面交给用户。
